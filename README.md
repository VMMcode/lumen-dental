# Lumen Dental — лендинг премиальной стоматологии

Тестовое задание: лендинг вымышленной стоматологии в центре Москвы. Название, дизайн-система, тексты и структура придуманы с нуля.

**Стек:** HTML + CSS + JavaScript без фреймворков, библиотек и сборки.

## Что внутри

**Обязательные блоки:** запись на приём, услуги, отзывы, карта.
**Дополнительно:** до/после, врачи, цены, FAQ, блок доверия с цифрами.

**Запись из любой точки страницы:**
- кнопка в sticky-хедере;
- плавающая панель на мобилке: звонок + запись, прячется у формы и в подвале;
- единая модалка с формой;
- кнопки записи в карточках услуг, врачей, цен и кейса. Модалка сама подставляет выбранную услугу или врача.

## Технические решения

| Что | Как и зачем |
|---|---|
| Архитектура CSS | Каскадные слои `@layer` + БЭМ. Порядок приоритета задан явно, без войны специфичности |
| Дизайн-токены | Палитра, шкала шрифтов, отступы и радиусы в `:root`. Типографика fluid через `clamp()`, без медиазапросов |
| Шрифты | Manrope + Onest, variable, self-hosted. `unicode-range` грузит только нужные наборы, знак ₽ лежит в отдельном файле на 1 КБ |
| Container queries | Форма раскладывается по ширине своего контейнера: в модалке одна колонка, в секции две. Вордмарк в подвале всегда ровно во всю ширину (`cqi`) |
| Модалка | Нативный `<dialog>`: фокус-ловушка и Esc из коробки. Анимация через `@starting-style`. На мобилке открывается как bottom sheet |
| Аккордеон | Анимация высоты `auto` через `grid-template-rows: 0fr → 1fr`, без расчётов в JS |
| Слайдеры | Нативный `scroll-snap`, стрелки с disabled-состоянием на краях, drag мышью на десктопе |
| До/после | Pointer events для мыши и тача. Скрытый `input[type=range]` даёт доступ с клавиатуры и для скринридеров |
| Карта | Яндекс.Карта грузится, только когда секция подъезжает к экрану (IntersectionObserver) |
| SEO | Семантика, один H1, мета- и OG-теги, микроразметка schema.org `Dentist` и `FAQPage` |
| Доступность | Skip-link, видимый фокус, ARIA-паттерны табов и аккордеона, `prefers-reduced-motion`, контраст по WCAG AA |

**Lighthouse:** 100 / 100 / 100 / 100 на десктопе. На мобилке 96 / 100 / 100 / 100.

## Состояния формы

Default → hover → focus → заполнено → валидно / ошибка поля → отправка (спиннер, поля заблокированы) → успех или ошибка отправки.

- Маска телефона `+7 (___) ___-__-__`, восьмёрка в начале заменяется на семёрку.
- Ошибка поля появляется после ухода с него, а не на первом символе.
- При отправке фокус переходит к первому полю с ошибкой.

> Бэкенда нет, отправка имитируется. **Чтобы увидеть ошибку отправки, введите имя «Ошибка».** Без интернета ошибка покажется тоже.

## Библиотеки

- [nice-select2](https://github.com/bluzky/nice-select2) 2.6.0 (MIT): кастомный выпадающий список в форме. Подключён как ES-модуль из `js/vendor/`, без jQuery и CDN. Стили библиотеки не используются, оформление своё — в `components.css`.

## Структура

```
index.html
css/
  reset.css       — сброс + порядок слоёв @layer
  fonts.css       — @font-face
  variables.css   — дизайн-токены
  base.css        — база, сетка, утилиты, анимации
  components.css  — кнопки, форма, слайдер и др.
  style.css       — стили блоков страницы
js/main.js
fonts/   — Manrope, Onest (woff2)
img/     — изображения в webp, фавикон, OG-картинка
```

## Запуск

Нужен локальный сервер, например Live Server в VS Code. JS подключён как ES-модуль, а браузер не запускает модули при открытии файла напрямую (`file://`).
